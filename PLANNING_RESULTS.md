## 🎮 Product Vision

### What It Will Be

**A mock cryptocurrency trading game where users:**

1. 📊 **View Real-Time Charts**
   - Professional TradingView candlestick charts
   - Live data from Binance WebSocket
   - Smooth 60 FPS performance

2. ✏️ **Draw Channel Lines**
   - Support lines (buy zones)
   - Resistance lines (sell zones)
   - Trend lines
   - Save and manage drawings

3. 🤖 **Automated Trading**
   - Set channel boundaries
   - Automatic buy when price hits support
   - Automatic sell when price hits resistance
   - Real-time trade execution

4. 💰 **Track Performance**
   - Start with $10,000 mock USD
   - Real-time balance updates
   - Profit/Loss calculations
   - Portfolio value tracking

5. 📜 **Trade History**
   - See all executed trades
   - Timestamps and prices
   - Color-coded for clarity
   - Trade statistics

6. 🎮 **Simple Controls**
   - On/Off toggle for trading
   - Reset button for new game
   - Clear status indicators

### Target Audience

- **Trading Beginners**: Learn without financial risk
- **Students**: Understand market mechanics
- **Developers**: See modern web development
- **Traders**: Test strategies risk-free
